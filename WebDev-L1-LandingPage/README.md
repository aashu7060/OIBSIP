# Landing Page – Kadak Chai Co.
 
**Track:** Web Development & Designing · **Level 1 · Task 1**
 
A static, responsive landing page for a fictional loose-leaf chai subscription brand.
 
## Tech
HTML5 and CSS3 only (no JavaScript).
 
## Feature checklist
- Sticky navigation bar with 4 links
- Hero with headline, subheadline and call-to-action button
- 3 content sections: Blends, How it works, Reviews
- Footer with contact and social link placeholders
- One colour palette (teal, marigold, chai brown, pale blue-grey)
- Responsive layout using Flexbox and CSS Grid, checked at mobile widths
- Intentional padding, margin and `box-sizing: border-box`
- Two font families, with clear heading and body sizes
## Run it
Open `index.html` in any browser.
